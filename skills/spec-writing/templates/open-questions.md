# Open Questions Template

- Place the open questions section at the end of the technical content. Each question references the section (and the
  code file, where relevant) it is about, and offers resolution options where possible.
- Remove a question when it is answered, and move the answer into the relevant section.

```markdown
## Open Questions

1. **Short title of the inconsistency or gap**: detailed description, with the section and code file it refers to.
   Question to address: question that must be answered to resolve the inconsistency or gap.
   Option 1: possible way to resolve the inconsistency or gap.
   Option 2: another possible way to resolve the inconsistency or gap.
2. ...
```
