# Architecture Document Template

File: `docs/architecture.md`. It describes approved and implemented architecture only.

The reader is a new developer who needs to navigate the code base.

- `## System View` contains a component diagram with the real component names.
- `## Repository Structure` contains a `tree` output of the important folders and files only.
- A story proposes architecture changes in its `## Architecture Changes` section. The final phase of the story updates
  this document.

```markdown
# Project Name

## Main Functionality and Use Cases

## Technology Stack

## System View

## Basic Data Structures

## Persistence Database Layer

## Repository Structure
```
